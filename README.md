# IPSLearning
This project implements the two-phase approach for extracting interaction kernels in many-particle systems as described in:
Shi, Y., Yang, W., & Hong, L. (2025). Extracting Interaction Kernels for Many-Particle Systems by a Two-Phase Approach.
This repository contains a set of Python codes for simulating and analyzing particle systems using Stochastic Differential Equations (SDEs) and Mean Field Equations (MFEs). The code provides tools for both numerical simulation and regression analysis to learn interaction kernels.

Requirements:
Python 3.8+
NumPy
Pandas
SciPy
Matplotlib
scikit-learn
Numba
joblib
tqdm
